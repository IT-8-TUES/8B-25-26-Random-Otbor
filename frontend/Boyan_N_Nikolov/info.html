What is Questure?

Questure is a progression-based social adventure platform where real-world activities become quests. Instead of simply tracking tasks, Questure turns exploration, challenges, and social interaction into a leveling system similar to a game. Users complete quests, upload proof, earn XP, level up, unlock progression titles, and play together with friends through shared quest sessions. The entire platform revolves around one gameplay loop: Discover → Accept → Complete → Upload Proof → Submit → Earn XP → Level Up

  1. Accounts, Profiles & Getting Started

    When first joining Questure, users create an account using:

    • Display name
    • Email
    • Password

    After logging in, Questure stores your account session and loads your personal profile, active quests, XP, and progression stats.

    The profile system acts as your identity across the platform. Users can customize several parts of their account, including:

    • Display name
    • Email
    • Bio
    • Avatar emoji

    The bio system supports up to 180 characters and allows players to describe themselves, their playstyle, or achievements. 

    Urban explorer • Photographer • LV.7 Adventurer

    Users can also choose a custom emoji avatar that appears throughout the platform in:

    • Friend lists
    • Quest sessions
    • Notifications
    • Profile pages
    • Social systems

    The profile page additionally tracks:

    • Current level
    • Total XP
    • Active quests
    • Completed quests

    Questure also supports password changing directly inside the account settings section.

  2. The Quest System

    The quest system is the core feature of Questure.

    A quest is a challenge, activity, or objective users complete in real life in exchange for XP rewards and progression.

    Every quest contains:

    • A title
    • Description
    • Banner emoji
    • Difficulty
    • XP reward
    • Tags/categories
    • Optional social features

    Questure supports different quest styles through tags such as:

    • Easy
    • Medium
    • Hard
    • Solo
    • Social
    • Group

    Quests are discovered through the Discover page, where users can:

    • Browse all quests
    • Search by keywords
    • Filter by difficulty or playstyle

    When selecting a quest, users are taken to a dedicated quest page where they can:

    • Read the full description
    • View rewards
    • Accept the quest
    • Upload proof
    • Invite friends
    • Submit completion

  3. Accepting, Tracking & Abandoning Quests

    Before starting a quest, the user must press the Accept button.

    Once accepted:

    • The quest becomes active
    • Upload systems unlock
    • Friend invites unlock
    • Session tracking starts
    • The quest appears in Active Quests

    Accepted quests are tracked on the Home page dashboard.

    Questure visually tracks progress through:

    • Progress bars
    • Upload states
    • Completion status
    • XP labels

    Quest states include:

    • Ready to start
    • In progress
    • Submitted
    • Completed

    Users may also abandon active quests if they no longer wish to continue.

    Completed quests become permanently tracked inside the user’s profile statistics.

  4. The XP & Leveling System

    Questure uses an RPG-style progression system based on XP (Experience Points).

    Every completed quest grants XP rewards based on difficulty and participation count.

    Current progression structure: 

    LV.1  → 0 XP
LV.2  → 500 XP
LV.3  → 1200 XP
LV.4  → 2500 XP
LV.5  → 4500 XP
LV.6  → 7000 XP
LV.7  → 10000 XP
LV.8  → 14000 XP
LV.9  → 19000 XP
LV.10 → 25000 XP

    After Level 10, users continue leveling infinitely using an extended XP scaling system.

    Questure also includes progression titles tied to XP ranges:

    • 0–499 XP → Beginner
    • 500–1199 XP → Newcomer
    • 1200–2499 XP → Explorer
    • 2500–4499 XP → Adventurer
    • 4500–6999 XP → Regular
    • 7000–9999 XP → Experienced
    • 10000–13999 XP → Advanced
    • 14000–18999 XP → Expert
    • 19000–24999 XP → Veteran
    • 25000+ XP → Elite

    These titles appear across profiles, friend lists, user cards, and social displays.

    The leveling system acts as the primary long-term progression mechanic of the platform.

  5. Quest Sessions, Friends & Multiplayer Gameplay

    Questure heavily encourages cooperative gameplay.

    When a quest is accepted, players can invite friends into a shared quest session.

    Quest sessions support:

    • Multiple participants
    • Shared progression
    • Session XP bonuses
    • Group activity

    The session system tracks:

    • Participants
    • Pending invites
    • Session leader
    • Maximum player count

    The quest leader controls important actions like:

    • Final submission
    • Participant management
    • Removing players from sessions

    Users receive quest invitations through the notification system and can instantly join active sessions.

    The multiplayer system transforms quests into cooperative experiences rather than isolated tasks.

  6. XP Bonuses & Group Rewards

    Questure rewards social participation through session bonus XP.

    The bonus system increases XP rewards depending on the number of participants in a quest session.

    The current formula gives roughly:

    • +5% XP per participant
    Base Quest Reward: 300 XP
3 Participants

    This encourages:

    • Cooperative gameplay
    • Friend interaction
    • Multiplayer exploration
    • Social progression

    The bonus is automatically calculated and distributed when the quest is submitted.

  7. Proof Upload & Quest Completion

    Questure uses a proof-based completion system.

    Many quests require users to upload photos proving the activity was completed.

    Photo uploads remain locked until:

    1. The quest is accepted
    2. The upload system unlocks

    After uploading:

    • Photos become attached to the quest
    • Progress updates
    • Submission requirements become available

    The upload system supports:

    • File uploads
    • Upload status tracking
    • Quest galleries
    • Shared session proof uploads

    To submit a quest:

    • The user must upload at least one proof photo
    • The quest must not already be completed
    • The session leader must perform the submission in multiplayer sessions

    After successful submission:

    • XP is awarded
    • The quest becomes completed
    • Progress statistics update
    • The quest leaves the active quest list

  8. Home Dashboard, Progress Tracking & Notifications

    The Home page acts as the central command hub of Questure.

    It displays:

    • Active quests
    • Current XP
    • Level
    • Quest progress
    • Friend activity
    • Notifications

    The active quest section displays recent accepted quests with:

    • Quest title
    • Difficulty badges
    • XP reward
    • Progress bars
    • Upload shortcuts

    Progress updates dynamically depending on:

    • Upload count
    • Submission state
    • Completion status

    Questure also includes a notification system for:

    • Friend requests
    • Quest invitations
    • Social activity
    • Session updates

    Unread activity is shown using a notification dot indicator.

    The dashboard is designed to give players a fast overview of their current progression and activity.

  9. Friends System & Social Features

    Questure contains a complete social system centered around friends and cooperative progression.

    Users can:

    • Search for players
    • Send friend requests
    • Accept requests
    • Deny requests
    • Remove friends

    Friend lists display:

    • Username
    • Avatar
    • Level
    • XP totals

    The platform also includes:

    • Friend search filters
    • Public profile viewing
    • Social progression visibility
    • Quest invitations

    Incoming friend requests are displayed in a dedicated request panel where users can instantly respond.

    This social structure is one of the main systems encouraging long-term engagement.

  10. Overall Gameplay Philosophy

    Questure is designed around the idea of turning real-life experiences into game progression.

    Instead of traditional achievements or simple task tracking, the platform combines:

    • RPG leveling systems
    • Social multiplayer mechanics
    • Exploration
    • Real-world activity
    • Progression rewards
    • Photo-based achievements

    The platform encourages users to:

    • Explore more places
    • Participate socially
    • Complete challenges
    • Build progression over time
    • Share experiences with friends

    At its core, Questure is meant to make ordinary activities feel meaningful, rewarding, and game-like through a persistent progression system.
